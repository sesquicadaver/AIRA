# Початок

## Що це?

AIRA Desktop допомагає виконувати локальні задачі й бачити чесний стан.

## Що зробити?

Відкрийте «Робота», опишіть задачу (наприклад Calculate 2 + 2), натисніть «Виконати» або Ctrl+Enter.

## Що має відбутися?

З’явиться відповідь зі статусом виконання, перевіркою та походженням — без підробленого VERIFIED.

## Що робити, якщо не вдалося?

Якщо нічого не запускається, відкрийте «Стан системи → Програма» і Старт. Довідка · F1 завжди доступна; Esc закриває лише довідку.
