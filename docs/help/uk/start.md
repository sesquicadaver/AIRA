# Початок

## Що це?

AIRA Desktop — локальне вікно для задач на цьому комп’ютері та чесного стану системи. Воно не вигадує ім’я моделі, перевірений результат чи мережевий стан, якого не спостерігали.

Довідка · F1 завжди доступна офлайн. Теми поставлені з цією версією — без інтернету й без LLM.

## Що зробити?

1. Відкрийте **Робота**.
2. Опишіть задачу своїми словами (наприклад `Calculate 2 + 2`).
3. Натисніть **Виконати** або **Ctrl+Enter** (⌘+Enter на Mac). Enter лише додає рядок.
4. Якщо нічого не запускається — **Стан системи → Програма → Старт**.

Довідку можна відкрити будь-коли; Esc закриває лише Довідку і не скасовує запуск і не чистить чернетку.

## Що має відбутися?

З’явиться відповідь зі статусом виконання, перевіркою та походженням. Вбудовані обчислення можуть успішно пройти без локальної мовної моделі. Походження чесне: mock ≠ перевірено; невизначена модель зазначена явно.

## Що робити, якщо не вдалося?

- Порожній текст відхиляється — спочатку введіть задачу.
- Якщо Старт не вдався, прочитайте банер проблеми й відкрийте Довідку для цього коду (контекстна F1 віддає перевагу останній проблемі).
- Якщо вузол був зупинений, Desktop може спочатку запустити його; якщо ні — дивіться **Програма**.
