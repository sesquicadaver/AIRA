# Поки задача виконується

## Що це?

**Виконуємо** означає очікування локального вузла. Це не вигаданий відсоток і не доказ участі віддаленого peer.

## Що зробити?

- Залиште вікно відкритим, якщо хочете побачити результат.
- Можна перейти в Стан системи / Параметри або відкрити F1 — чернетка Роботи лишається.
- Не очікуйте другого паралельного запуску, доки поточний не завершиться.

## Що має відбутися?

Коли вузол відповідає, у Роботі з’являється відповідь. Оновлення стану в Системі не вигадує з’єднання.

## Що робити, якщо не вдалося?

Якщо **Виконуємо** триває надто довго:

1. **Стан системи → З’єднання → Оновити**.
2. Прочитайте останні події / банер проблеми.
3. help:network.reachability при тривалому UNKNOWN; help:node.lifecycle, якщо програма зупинилась.

Закриття вікна само по собі не скасовує роботу; Стоп — лише коли ви свідомо зупиняєте програму.

## Пов'язані теми

- help:work.result — читання готової відповіді
- help:work.submit — новий запуск
- help:network.reachability — чесний банер доступності
