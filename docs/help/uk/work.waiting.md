# Поки задача виконується

## Що це?

«Виконуємо» означає очікування локального вузла — не вигаданий відсоток.

## Що зробити?

Можна змінювати розділи й відкривати Довідку без втрати чернетки.

## Що має відбутися?

Після завершення відповідь з’явиться в «Роботі». Закриття вікна само по собі не скасовує роботу.

## Що робити, якщо не вдалося?

Якщо довго «Виконуємо», оновіть стан системи й прочитайте останні події / проблему.
