# Читати результат

## Що це?

Спочатку **відповідь**, далі статус виконання, перевірка й **походження**. Технічні хеші та сирий JSON — у «Деталях», не як перше, що треба розшифрувати.

## Що зробити?

1. Прочитайте текст відповіді.
2. Прочитайте **Походження**: mock ≠ перевірено; невизначена чи неактивна модель зазначена; локальна генерація не стає VERIFIED автоматично.
3. Відкривайте **Деталі** лише для технічного JSON.

## Що має відбутися?

Чесний рядок provenance для цього запуску. Вбудовані обчислення можуть показати VERIFIED, коли шлях виконання справді перевірив результат; вільна генерація без того шляху не підробляє VERIFIED.

## Що робити, якщо не вдалося?

- Відповіді ще немає → очікування (help:work.waiting) або події.
- Стани collapse / needs-human можуть не мати фейкової відповіді — йдіть за повідомленням.
- Генерація впала через відсутність моделі → help:model.unavailable.

## Пов'язані теми

- help:work.submit — ще один запуск
- help:model.unavailable — коли модель потрібна, але відсутня
- help:start — шлях першого запуску
