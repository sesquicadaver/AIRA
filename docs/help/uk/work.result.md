# Читати результат

## Що це?

Спочатку відповідь, далі статус виконання, перевірка й походження.

## Що зробити?

Прочитайте відповідь і рядок «Походження» (mock ≠ перевірено; невизначена модель зазначена явно).

## Що має відбутися?

Чесне походження цього запуску — без фейкового VERIFIED.

## Що робити, якщо не вдалося?

У «Деталях» — технічний JSON. Якщо відповіді ще немає, зачекайте або перегляньте події.
