# Доступність

## Що це?

Доступність — **останнє спостереження** mesh: пряма, relay, лише outbound, лише локально, невідомо або offline, коли це справді спостерігали. Застаріле чи unknown не малюється як підтверджене глобальне з’єднання.

## Що зробити?

1. **Стан системи → З’єднання**.
2. **Оновити** — новий запит спостереження.
3. Читайте банер і час спостереження — не лише кількість адресної книги.

## Що має відбутися?

Чесний банер. Рядки AddressBook не рахуються як живі сесії. UNKNOWN ≠ OFFLINE.

## Що робити, якщо не вдалося?

- Триває UNKNOWN → peer listen, firewall, чи профіль взагалі стартує peer.
- Програма зупинена → help:node.lifecycle.
- Щойно змінили профіль → help:settings.apply і help:network.connect.
