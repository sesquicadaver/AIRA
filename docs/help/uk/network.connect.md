# З’єднання з учасниками

## Що це?

**З’єднання** описує, як цей комп’ютер пов’язаний з іншими учасниками AIRA за обраним мережевим профілем (типово P0 — лише локально). Записи адресної книги — збережені підказки, не живі сесії.

## Що зробити?

1. **Стан системи → З’єднання → Технічні подробиці** (або Параметри → З’єднання).
2. Змінюйте профіль мережі лише розуміючи контракт профілю.
3. Якщо Параметри показують **потрібен перезапуск** — **Програма → Стоп**, потім **Старт**.

Не вмикайте public bind і не auto-trust незнайомців за порадою з Довідки — це лишається opt-in CLI / advanced.

## Що має відбутися?

Чесний підсумок з’єднання. Збережені учасники ≠ підключені сесії. UNKNOWN / LOCAL ONLY ≠ підтверджений OFFLINE.

## Що робити, якщо не вдалося?

Оновіть стан. Якщо банер лишається неперевіреним — help:network.reachability. Проблеми invite/trust — help:network.trust. Apply/restart — help:settings.apply.

- help:network.trust — запрошення і довіра
