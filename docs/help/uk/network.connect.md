# З’єднання з учасниками

## Що це?

З’єднання описує, як цей комп’ютер пов’язаний з іншими учасниками AIRA.

## Що зробити?

Профіль мережі — у «Стан системи → З’єднання → Технічні подробиці»; за потреби Стоп і Старт.

## Що має відбутися?

Збережені учасники (адресна книга) — не те саме, що живі сесії.

## Що робити, якщо не вдалося?

UNKNOWN ≠ OFFLINE. Оновіть стан, якщо банер лишається неперевіреним.
