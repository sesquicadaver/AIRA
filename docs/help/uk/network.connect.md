# З’єднання з учасниками

## Що це?

**З’єднання** — як цей комп’ютер **готує** роботу з іншими учасниками AIRA. Типовий профіль **P0** — лише локально. Рядки адресної книги — збережені учасники, не живі сесії. UNKNOWN — це не те саме, що OFFLINE.

Ця тема — шлях **налаштування**: запрошення → профіль із peer → Стоп/Старт → чесний стан. Він налаштовує довіру й локальну мережу. Він **сам по собі не** завершує автентифіковану віддалену peer-сесію з іншим комп’ютером.

## Межа сценарію (прочитайте)

- **Налаштування ≠ віддалена сесія.** Імпорт запрошення + P1/P2 + Стоп/Старт застосовує локальні параметри й може збільшити книгу. Живі сесії з’являються лише коли сесію справді спостерігають — не тому, що кроки setup завершились.
- **Loopback ≠ адреса для dial.** Типовий Desktop listen прив’язаний до loopback. Експортований listener на loopback — **не** адреса, за якою інший комп’ютер може набрати цей вузол. Успішний Стоп/Старт не означає «під’єднались до когось іншого».
- Public bind і auto-trust лишаються opt-in advanced/CLI — Довідка ніколи не вмикає їх як типовий шлях.

Підтверджений remote dial — **opt-in** у **Технічні подробиці → Dial до піра**: довірений peer + **явна** dial-адреса. Спроба dial виконується **поза UI-потоком**, тож Довідка (F1) і навігація лишаються доступними під час очікування. Успіх зберігає evidence handshake і може показати **останню підтверджену перевірку** (сесію після перевірки закрито) — це **не** вигадує живу сесію чи DIRECT із самого setup, а Desktop listen лишається loopback за замовчуванням.

## Що зробити?

Канонічний сценарій налаштування (базовий шлях без обов’язкового розгортання «Технічні подробиці»):

1. **Імпортуйте запрошення** — у **Стан системи → З’єднання** скористайтесь **Імпортувати запрошення…** / імпорт JSON або QR (friend invite). Це довіра до відомого peer; саме discovery ще не довіра (див. help:network.trust).
2. **Увімкніть peer-профіль** — оберіть **P1** або **P2** (приватна мережа з peer listen). P0 лишається лише локальним. Якщо кнопка каже **Увімкнути приватну мережу** — натисніть її.
3. **Застосуйте Стоп → Старт** — якщо Параметри або З’єднання показують **потрібен перезапуск**, у **Стан системи → Програма** натисніть **Стоп**, потім **Старт**. Закриття вікна не зупиняє AIRA.
4. **Чесно перевірте стан** — читайте людський підсумок З’єднання і за потреби **Оновити**. Очікуйте Збережено ≠ Застосовано, доки runtime не підтвердить; ріст книги без вигаданих живих сесій. Деталі доступності — help:network.reachability.

## Що має відбутися?

Після invite + P1/P2 + перезапуску: Збережено ≠ Застосовано, доки runtime не підтвердить; «потрібен перезапуск» зникає після Стоп/Старт; книга може зрости без вигаданих живих сесій; на З’єднанні видно один наступний крок (CTA), якщо setup ще неповний. **Не** вважайте віддалену peer-сесію завершеною лише тому, що ці кроки пройшли на loopback.

## Що робити, якщо не вдалося?

- Немає запрошення / порожня книга → імпорт ще раз (help:network.trust).
- Досі P0 / «Увімкнути приватну мережу» → P1 або P2, потім перезапуск.
- «Потрібен перезапуск» лишається → Стоп, потім Старт (help:settings.apply, help:node.lifecycle).
- Банер лишається unknown після peer-профілю → Оновити й help:network.reachability (UNKNOWN ≠ OFFLINE).
- Очікували «з’єднання з іншим ПК», але лише loopback listen → ця межа Довідки: setup ≠ remote dial.
