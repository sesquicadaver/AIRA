# Застосувати параметри

## Що це?

Параметри зберігаються на диск; частина мережевих значень застосовується лише після Стоп → Старт.

## Що зробити?

Загальні опції можна змінювати будь-коли. Для З’єднання порівняйте «Збережено» й «Застосовано».

## Що має відбутися?

Миттєві параметри діють одразу; мережа/listen показують «потрібен перезапуск» до Старт.

## Що робити, якщо не вдалося?

Закриття вікна не зупиняє AIRA. Використовуйте «Програма → Стоп».
