# Застосувати параметри

## Що це?

Параметри **зберігаються** на диск під час зміни. Частина значень (профіль мережі, listen) **застосовується** до запущеної програми лише після Зупинити вузол → Запустити вузол. Закриття вікна **не** зупиняє AIRA.

**Параметри ≠ Стан системи:** редагуйте мережевий профіль і peer listen у **Параметри → З’єднання**. **Стан системи → З’єднання** показує спостережуваний стан, запрошення й одну коригувальну CTA — не другу форму налаштувань.

## Що зробити?

1. **Загальні** опції (мова, відкривати UI при старті, autostart) — будь-коли, без бейджа перезапуску вузла.
2. Редагуйте **З’єднання** (профіль, peer listen, P3|P4) у Параметрах. Порівняйте **Збережено** й **Застосовано**. Якщо Застосовано = **не підтверджено**, зробіть Запустити вузол (або дочекайтесь статусу) — значення з робочого вузла, не лише з диска.
3. Коли бачите **потрібен перезапуск** — **Програма → Зупинити вузол**, потім **Запустити вузол**.

## Що має відбутися?

Миттєві параметри діють одразу. Мережа/listen лишаються позначеними, доки успішний Запустити вузол не синхронізує applied runtime.

## Що робити, якщо не вдалося?

Якщо Запустити вузол після зміни профілю падає — проблема й help:node.lifecycle. Що означає профіль — help:network.connect. Орієнтація після apply — help:start.

## Пов'язані теми

- help:node.lifecycle — Зупинити вузол / Запустити вузол щоб застосувати
- help:network.connect — параметри з’єднання
- help:start — перші кроки після застосування
