# Застосувати параметри

## Що це?

Параметри проходять чесний цикл: **Змінено** (чернетка в UI) → **Збережено** (на диску) → **Застосовано** (підтверджено запущеним вузлом) → або **потрібен перезапуск**, коли Збережено ≠ Застосовано для мережі/listen. Закриття вікна **не** зупиняє AIRA.

**Параметри ≠ Стан системи:** редагуйте мережевий профіль і peer listen у **Параметри → З’єднання**. **Стан системи → З’єднання** показує спостережуваний стан, запрошення й одну коригувальну CTA — не другу форму налаштувань.

## Що зробити?

1. **Загальні** опції (мова, відкривати UI при старті, autostart) — будь-коли, без бейджа перезапуску вузла.
2. Редагуйте **З’єднання** (профіль, peer listen, P3|P4) у Параметрах. Якщо бейдж **Змінено** — **Зберегти чернетку** або **Скасувати чернетку** (Скасувати відновлює значення з диска).
3. Порівняйте **Збережено** й **Застосовано**. Якщо Застосовано = **не підтверджено**, зробіть Запустити вузол (або дочекайтесь статусу) — значення з робочого вузла, не лише з диска.
4. Коли бачите **потрібен перезапуск** — **Програма → Зупинити вузол**, потім **Запустити вузол**.
5. Якщо під бейджем є **Помилка застосування** — виправте значення (наприклад peer listen) і Збережіть знову; це конкретна помилка, не тихий успіх.

## Що має відбутися?

Миттєві параметри діють одразу. Незбережені правки Connection лишаються **Змінено**, доки не Зберегти/Скасувати. Мережа/listen лишаються позначеними, доки успішний Запустити вузол не синхронізує applied runtime.

## Що робити, якщо не вдалося?

- Apply/persist впав → читайте рядок **Помилка застосування** у Параметрах; не вважайте диск оновленим.
- Якщо Запустити вузол після зміни профілю падає — проблема й help:node.lifecycle.
- Що означає профіль — help:network.connect. Орієнтація після apply — help:start.

## Пов'язані теми

- help:node.lifecycle — Зупинити вузол / Запустити вузол щоб застосувати
- help:network.connect — параметри з’єднання
- help:start — перші кроки після застосування
