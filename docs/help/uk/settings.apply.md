# Застосувати параметри

## Що це?

Параметри **зберігаються** на диск під час зміни. Частина значень (профіль мережі, listen) **застосовується** до запущеної програми лише після Стоп → Старт. Закриття вікна **не** зупиняє AIRA.

## Що зробити?

1. **Загальні** опції (мова, відкривати UI при старті, autostart) — будь-коли, без бейджа перезапуску вузла.
2. Для **З’єднання** / listen порівняйте **Збережено** й **Застосовано**. Якщо Застосовано = **не підтверджено**, зробіть Старт (або дочекайтесь статусу) — значення з робочого вузла, не лише з диска.
3. Коли бачите **потрібен перезапуск** — **Програма → Стоп**, потім **Старт**.

## Що має відбутися?

Миттєві параметри діють одразу. Мережа/listen лишаються позначеними, доки успішний Старт не синхронізує applied runtime.

## Що робити, якщо не вдалося?

Якщо Старт після зміни профілю падає — проблема й help:node.lifecycle. Що означає профіль — help:network.connect. Орієнтація після apply — help:start.

## Пов'язані теми

- help:node.lifecycle — Стоп / Старт щоб застосувати
- help:network.connect — параметри з’єднання
- help:start — перші кроки після застосування
