# Виконати задачу

## Що це?

**Виконати** надсилає текст задачі на локальний вузол AIRA під наглядом Desktop. Лише один активний запуск; UI не блокується на HTTP у циклі малювання.

## Що зробити?

1. Тримайте фокус у чернетці Роботи.
2. **Enter** — новий рядок.
3. **Виконати** або **Ctrl+Enter** (⌘+Enter на Mac), коли дія доступна.
4. Можна змінювати розділи й відкривати Довідку — чернетка лишається при помилках валідації й невдалому запуску.

Не тисніть Виконати повторно під час активного запуску — другий натиск не створює дубліката.

## Що має відбутися?

Екран переходить у очікування, потім показує відповідь зі статусом, перевіркою та походженням. Закриття Довідки не скасовує запуск.

## Що робити, якщо не вдалося?

- Порожній текст → відхилення з проблемою (Довідка на `work.submit`).
- Вузол зупинено → Desktop може спочатку зробити Старт; якщо ні — help:node.lifecycle.
- Немає моделі для генерації → help:model.unavailable; обчислення на кшталт `Calculate 2 + 2` можуть працювати без LLM.

## Пов'язані теми

- help:work.waiting — поки виконується запуск
- help:work.result — як читати відповідь і provenance
- help:node.lifecycle — Старт локальної програми
