# Виконати задачу

## Що це?

«Виконати» надсилає текст задачі на локальний вузол AIRA.

## Що зробити?

Enter — новий рядок. Ctrl+Enter (⌘+Enter на Mac) запускає, коли дія доступна. Чернетка лишається при F1 чи помилці.

## Що має відбутися?

Один активний запуск; повторне натискання не створює дубліката.

## Що робити, якщо не вдалося?

Порожній текст відхиляється. Якщо вузол зупинено, Desktop може спочатку запустити його. Перевірте «Стан системи», якщо Старт не вдався.
