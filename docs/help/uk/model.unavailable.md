# Модель недоступна

## Що це?

Задача потребувала локальної генерації тексту, але підходящий backend моделі не готовий або не вибраний. Це fail-closed сигнал — не тихий fallback на вигадану модель.

## Що зробити?

1. Якщо можливо — вбудовані обчислення.
2. Активуйте / зареєструйте локальну модель у model layer і повторіть.
3. Якщо щойно змінювали параметри моделей — переконайтесь, що вони застосовані (help:settings.apply).

## Що має відбутися?

Детерміноване виконання може успішно завершитися без LLM. Генерація лишається недоступною, доки немає реального backend.

## Що робити, якщо не вдалося?

Не очікуйте VERIFIED для вільного тексту без активованого backend. Якщо Виконати не може підняти вузол — help:node.lifecycle. Про вибір моделі — help:model.select.

## Пов'язані теми

- help:model.select — вибір / підготовка локальної моделі
- help:work.submit — повторити задачу
- help:work.result — як показується provenance після генерації
