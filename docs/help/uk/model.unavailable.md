# Модель недоступна

## Що це?

Потрібна локальна модель не готова або не вибрана.

## Що зробити?

Використовуйте вбудовані обчислення або підготуйте модель через model layer.

## Що має відбутися?

Детерміновані задачі можуть успішно завершитися без LLM.

## Що робити, якщо не вдалося?

Не очікуйте VERIFIED від генерації тексту без активованого backend.
