# Довіра

## Що це?

Довіра визначає, кого ви приймаєте як учасника. Саме discovery — ще не довіра. Desktop ніколи не робить auto-trust незнайомців.

## Що зробити?

1. Технічні подробиці **З’єднання**.
2. Імпортуйте friend invite (файл або QR), коли свідомо довіряєте peer.
3. Зміни профілю мережі лишаються явними; вищі профілі — fail-closed, доки не налаштовані.

## Що має відбутися?

**DISCOVERED** ≠ **TRUSTED**. Імпортовані запрошення видно в tooling довіри / книги без вигаданих живих сесій.

## Що робити, якщо не вдалося?

Якщо імпорт не вдався — перевірте файл/QR і повторіть. Проблеми доступності окремо — help:network.reachability. Профіль з’єднання — help:network.connect.
