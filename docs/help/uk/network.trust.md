# Довіра

## Що це?

Довіра визначає, кого ви приймаєте як учасника. Саме discovery — ще не довіра. Desktop ніколи не робить auto-trust незнайомців.

## Що зробити?

1. У **Стан системи → З’єднання** (основна поверхня — не лише технічні подробиці) імпортуйте friend invite (JSON або QR), коли свідомо довіряєте peer.
2. Далі за сценарієм з’єднання: після імпорту ввімкніть **P1/P2**, якщо ще P0, потім **Стоп → Старт**, коли потрібен перезапуск — див. help:network.connect.
3. Вищі профілі й advanced discovery лишаються fail-closed, доки ви їх свідомо не налаштуєте.

## Що має відбутися?

**DISCOVERED** ≠ **TRUSTED**. Імпортовані запрошення видно в tooling довіри / адресної книги без вигаданих живих сесій. На З’єднанні може з’явитись крок **Імпортувати запрошення…**, якщо книга порожня. Імпорт — це налаштування довіри, не доказ живої віддаленої сесії (межа в help:network.connect).

## Що робити, якщо не вдалося?

Якщо імпорт не вдався — перевірте файл/QR і повторіть. Проблеми доступності окремо — help:network.reachability. Профіль / перезапуск — help:network.connect і help:settings.apply.

## Пов'язані теми

- help:network.connect — сценарій invite → профіль → перезапуск (**налаштування**; setup ≠ remote; loopback ≠ dial)
- help:network.reachability — сесії vs книга
- help:settings.apply — коли параметри потребують перезапуску
