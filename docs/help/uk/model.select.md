# Вибір моделі

## Що це?

Локальні моделі живуть у model / execution layer. Вони **не** частина `aira-core`, не GPU-маркетплейс і не вигадуються екраном Роботи.

## Що зробити?

- У **Параметри → Моделі** оберіть/активуйте **локальну** сумісну модель, коли потрібен LLM (поправка RFC-0159 від 2026-09-10 — анти-узурпація однієї моделі).
- CLI `aira models scan|list|activate` лишається чинним.
- Для детермінованої математики на кшталт `Calculate 2 + 2` віддавайте перевагу вбудованим обчисленням.

## Що має відбутися?

Відсутність моделі не блокує задачі без LLM. Desktop окремо показує **selected**, **ready** і **used** — без вигаданого імені й без копіювання selected у used. Вибір моделі **не** означає VERIFIED.

## Що робити, якщо не вдалося?

Якщо генерація падає через відсутність активації — help:model.unavailable. Порожнє поле моделі ≠ успішний локальний LLM. Якщо вузол Running — це про Capability моделі, а не «AIRA зупинена».

## Пов'язані теми

- help:model.unavailable — потрібна модель не готова
- help:settings.apply — де параметри збережені vs застосовані
- help:work.submit — запуск без вигаданої моделі
