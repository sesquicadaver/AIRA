# Вибір моделі

## Що це?

Локальні моделі належать до model / execution layer — **не** `aira-core`, не GPU-маркетплейс і не вигадуються екраном Роботи. Довідка працює **офлайн** (вбудовані статті; без мережі й без LLM для читання цієї теми).

**Параметри ≠ Стан системи:** каталог змінюйте лише в **Параметри → Моделі**. **Стан системи → Модель** показує **selected**, **ready** і **used** як спостережувані факти — це не другий редактор каталогу.

## Що зробити?

Канонічний шлях Desktop (CLI не обов’язковий):

1. Відкрийте **Параметри → Моделі**.
2. **Скан** локального lifecycle-каталогу (або **Дозволити локальне додавання** → **Додати файл…** для локального weight-файлу).
3. **Вибрати** Auto або конкретний рядок. Вибір **не** означає VERIFIED.
4. **Підготувати**, якщо рядок ще не ready; читайте reason готовності в каталозі.
5. У **Роботі** оберіть виконавець **Авто**, **Конкретна модель** або **Порівняти**. Вбудовані обчислення (наприклад `Calculate 2 + 2`) **не** потребують моделі і не для Порівняти.
6. **Порівняти** потребує двох **різних** доступних моделей з каталогу (A і B). Обидві мають бути ready перед Виконати. A і B йдуть послідовно на той самий чернетці; якщо B падає — результат A лишається; **тихої підміни** tip чи іншої моделі немає.
7. Якщо на Роботі банер **demo / reference mock** — відкрийте **Параметри → Моделі**: mock-генерація — не реальний локальний LLM (див. help:work.result).

Опційний інструмент (не обов’язок GUI-шляху): `aira models scan|list|activate`.

## Що має відбутися?

- Відсутність моделі **не** блокує задачі без LLM (готовність math ≠ generate).
- Desktop тримає **selected ≠ ready ≠ used** чесно — без вигаданого імені й без копіювання selected у used.
- Вибір / Підготувати / Select ніколи тихо не означають VERIFIED для вільного тексту.
- Порівняти ніколи тихо не підміняє неготову модель tip або іншим рядком каталогу.

## Що робити, якщо не вдалося?

- Генерація заблокована, бо нічого не ready → help:model.unavailable (ті самі кроки Параметри → Моделі).
- Порівняти заблоковано, бо A/B порожні, однакові або не ready → виправте ногу в Параметри → Моделі; не очікуйте, що Auto tip заповнить прогалину.
- Порожнє поле або «модель не вибрано» ≠ успішний локальний LLM.
- Якщо вузол Running — це Capability моделі, а не «AIRA зупинена» (help:node.lifecycle лише якщо не вдався Запустити вузол).

## Пов'язані теми

- help:model.unavailable — потрібна модель не готова
- help:settings.apply — де параметри збережені vs застосовані
- help:work.submit — запуск без вигаданої моделі
- help:work.result — банер mock і requested / applied / executed
