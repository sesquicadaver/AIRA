# Вибір моделі

## Що це?

Локальні моделі живуть у model / execution layer. Вони **не** частина `aira-core`, не GPU-маркетплейс і не вигадуються екраном Роботи.

## Що зробити?

- Перегляньте опції моделей у **Параметри → Моделі**, якщо доступні.
- Готуйте / активуйте моделі задокументованим tooling (`aira models` / реєстрація в plane) поза цією статтею.
- Для детермінованої математики на кшталт `Calculate 2 + 2` віддавайте перевагу вбудованим обчисленням.

## Що має відбутися?

Відсутність моделі не блокує задачі без LLM. Коли модель потрібна, Desktop каже про це явно, а не вигадує ім’я.

## Що робити, якщо не вдалося?

Якщо генерація падає через відсутність активації — help:model.unavailable. Порожнє поле моделі ≠ успішний локальний LLM.

## Пов'язані теми

- help:model.unavailable — потрібна модель не готова
- help:settings.apply — де параметри збережені vs застосовані
- help:work.submit — запуск без вигаданої моделі
