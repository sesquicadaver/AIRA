# Вибір моделі

## Що це?

Локальні моделі — не Core і не маркетплейс.

## Що зробити?

Інвентар моделей керується поза цією темою (aira models / Параметри → Моделі).

## Що має відбутися?

Відсутність моделі не блокує вбудовані обчислення на кшталт Calculate 2 + 2.

## Що робити, якщо не вдалося?

Якщо генерація тексту падає, спочатку активуйте локальну модель — екран її не вигадує.
