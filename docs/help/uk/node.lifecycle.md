# Старт і стоп

## Що це?

**Програма** — supervised локальний процес AIRA на цьому комп’ютері. **Стан системи → Програма** — місце для Старт, Стоп і Оновити, а не друге джерело істини ledger.

## Що зробити?

1. **Стан системи → Програма**.
2. **Старт** піднімає вузол; **Стоп** свідомо зупиняє.
3. **Оновити** — нове спостереження стану.
4. **Вийти** закриває вікно після Стоп, коли ви залишаєте застосунок.

Саме закриття вікна — не Стоп (див. help:settings.apply).

## Що має відбутися?

Статус відображає supervised node. Після Старт Параметри можуть перейти з «потрібен перезапуск» у Застосовано для мережевих значень.

## Що робити, якщо не вдалося?

Прочитайте банер проблеми й відкрийте контекстну Довідку (F1). Порожній submit у Роботі може спочатку пробувати Старт — якщо ні, виправте Програму перед help:work.submit. Чесність мережі після Старт — help:network.reachability.

## Пов'язані теми

- help:settings.apply — коли з’являється «потрібен перезапуск»
- help:start — перші дії після Старт
- help:network.reachability — стан після підняття вузла
