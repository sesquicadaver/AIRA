# Старт і стоп

## Що це?

Програма — локальний процес AIRA на цьому комп’ютері.

## Що зробити?

У «Стан системи → Програма» — Старт, Стоп або Оновити. Вийти закриває вікно після Стоп.

## Що має відбутися?

Статус відображає supervised node — не друге джерело істини.

## Що робити, якщо не вдалося?

Якщо Старт не вдався, прочитайте повідомлення проблеми й Довідку для цього коду.
