# Старт і стоп

## Що це?

**Програма** — supervised локальний процес AIRA на цьому комп’ютері. **Стан системи → Програма** — місце для **Запустити вузол**, **Зупинити вузол** і **Оновити стан**, а не друге джерело істини ledger.

## Що зробити?

1. **Стан системи → Програма**.
2. **Запустити вузол** піднімає вузол; **Зупинити вузол** свідомо зупиняє.
3. **Оновити стан** — нове спостереження стану.
4. **Завершити AIRA** закриває вікно після Зупинити вузол, коли ви залишаєте застосунок.

Саме закриття вікна — не Зупинити вузол (див. help:settings.apply).

## Що має відбутися?

Статус відображає supervised node. Після Запустити вузол Параметри можуть перейти з «потрібен перезапуск» у Застосовано для мережевих значень.

## Що робити, якщо не вдалося?

Прочитайте банер проблеми й відкрийте контекстну Довідку (F1). Порожній submit у Роботі може спочатку пробувати Запустити вузол — якщо ні, виправте Програму перед help:work.submit. Чесність мережі після Запустити вузол — help:network.reachability.

## Пов'язані теми

- help:settings.apply — коли з’являється «потрібен перезапуск»
- help:start — перші дії після Запустити вузол
- help:network.reachability — стан після підняття вузла
