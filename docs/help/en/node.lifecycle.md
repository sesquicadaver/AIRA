# Start and stop

## What is this?

**Program** is the supervised local AIRA process on this computer. System → Program is the place to **Start node**, **Stop node**, and **Refresh status** — not a second ledger of truth.

## What to do?

1. Open **System → Program**.
2. **Start node** to bring the node up; **Stop node** to shut it down deliberately.
3. **Refresh status** updates observed status.
4. **Exit AIRA** closes the window after Stop node when you leave the app.

Closing the window alone is not Stop node (see help:settings.apply).

## What should happen?

Status reflects the supervised node. After Start node, Settings can move from Restart needed to Applied for network values.

## If it failed?

Read the problem banner and open contextual Help (F1). Empty Work submit may try Start node first — if that fails, fix Program before retrying help:work.submit. Network honesty after Start node — help:network.reachability.
