# Choosing a model

## What is this?

Local models are not part of Core and are not a marketplace.

## What to do?

Model inventory is managed outside this Help topic (aira models / Settings → Models).

## What should happen?

Missing a model does not block built-in calculation such as Calculate 2 + 2.

## If it failed?

If text generation fails, activate a local model first — this screen never invents one.
