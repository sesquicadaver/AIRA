# Apply settings

## What is this?

Settings are saved on disk; some network values apply only after Stop → Start.

## What to do?

Change General options anytime. For Connection, compare Saved vs Applied on Settings.

## What should happen?

Immediate prefs apply now; network/listen show Restart needed until Start.

## If it failed?

Closing the window does not stop AIRA. Use System → Program → Stop.
