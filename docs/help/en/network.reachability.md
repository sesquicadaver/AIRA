# Reachability

## What is this?

Reachability is what was last observed — direct, relay, local-only, or unknown.

## What to do?

Refresh on System → Connection. Do not treat address-book count as live sessions.

## What should happen?

You see an honest banner and observation time.

## If it failed?

If UNKNOWN persists, check peer listen and firewall; local-only is not a global link.
