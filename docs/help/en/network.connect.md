# Connect to participants

## What is this?

**Connection** describes how this computer relates to other AIRA participants under the selected network profile (P0 local-only by default). Address-book entries are saved hints — not live sessions.

## What to do?

1. Open **System → Connection → Technical details** (or Settings → Connection).
2. Change the network profile only when you understand the profile contract.
3. If Settings shows **Restart needed**, use **System → Program → Stop**, then **Start**.

Never enable public bind or auto-trust strangers from Help advice — those remain opt-in CLI / advanced paths.

## What should happen?

You see an honest connection summary. Saved participants ≠ connected sessions. UNKNOWN / LOCAL ONLY are not the same as confirmed OFFLINE.

## If it failed?

Refresh status. If the banner stays unverified, read help:network.reachability. For invite/trust problems, see help:network.trust. For apply/restart, see help:settings.apply.
