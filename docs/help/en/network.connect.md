# Connect to participants

## What is this?

Connection describes how this computer relates to other AIRA participants.

## What to do?

Change network profile under System → Connection → Technical details, then Stop and Start if Settings says restart is needed.

## What should happen?

Saved participants (address book) are not the same as live sessions.

## If it failed?

UNKNOWN is not OFFLINE. Refresh status if the banner stays unverified.
