# Getting started

## What is this?

AIRA Desktop helps you run local tasks and see honest status.

## What to do?

Open Work, describe a task (for example Calculate 2 + 2), press Run or Ctrl+Enter.

## What should happen?

You get an answer with run status, check, and origin — without inventing a verified result.

## If it failed?

If nothing runs, open System → Program and Start. Use Help · F1 any time; Esc closes Help only.
