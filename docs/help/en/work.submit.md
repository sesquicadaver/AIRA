# Run a task

## What is this?

Run sends your task text to the local AIRA node.

## What to do?

Enter adds a new line. Ctrl+Enter (⌘+Enter on Mac) runs when available. Your draft stays if Help opens or a run fails.

## What should happen?

One run is active at a time; a second press does not create a duplicate.

## If it failed?

Empty text is rejected. If the node is stopped, Desktop may start it first. Check System if Start fails.
