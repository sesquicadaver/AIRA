# Trust

## What is this?

Trust decides whom you accept as a participant. Discovery alone is not trust. Desktop must never auto-trust strangers.

## What to do?

1. Open **System → Connection** technical details.
2. Import a friend invite (file or QR) when you intend to trust that peer.
3. Keep network profile changes explicit; higher profiles stay fail-closed until configured.

## What should happen?

**DISCOVERED** is not **TRUSTED**. Invites you import are visible in the trust / book tooling without inventing live sessions.

## If it failed?

If import fails, check the invite file or QR and retry. Reachability problems are separate — see help:network.reachability. Connection profile issues — help:network.connect.
