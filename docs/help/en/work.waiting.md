# While a task runs

## What is this?

**Running** means Desktop is waiting on the local node. It is not a made-up progress percentage and not proof that a remote peer is involved.

## What to do?

- Leave the window open if you want to watch the result arrive.
- You may switch to System or Settings, or open Help · F1 — the Work draft stays.
- Do not expect Run to start a second parallel job until the current one finishes.

## What should happen?

When the node returns, Work shows the answer. Refresh on System updates observed status without inventing connectivity.

## If it failed?

If **Running** lasts far longer than usual:

1. Open **System → Connection** and Refresh.
2. Read **Recent events** / the problem banner.
3. Check help:network.reachability if the banner stays UNKNOWN, and help:node.lifecycle if the program stopped.

Closing the window does not by itself cancel in-flight work; use Stop only when you intend to stop the program.
