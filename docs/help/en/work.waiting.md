# While a task runs

## What is this?

Running means Desktop is waiting on the local node — not a made-up progress percent.

## What to do?

Keep the window open; you can switch sections or open Help without losing the draft.

## What should happen?

When finished, the answer appears on Work. Closing the window does not cancel work by itself.

## If it failed?

If it stays Running too long, refresh System status and read Recent events / problems.
