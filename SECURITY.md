# Security Policy

## Reporting

Report security issues privately to the repository maintainers (GitHub Security Advisories preferred).

## MVP baseline

- Network disabled for CSU by default (when runtime exists)
- Shell execution disabled by default
- Unsigned CSU / Artifacts rejected
- Private Artifacts denied by default
- Secrets must never appear in Events

This repository currently contains a **workspace skeleton** only; runtime security controls land with Core/Policy milestones.
